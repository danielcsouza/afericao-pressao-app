# Diário da Pressão

App Flutter (Android) para anotar a pressão arterial: um caderno digital, sem diagnóstico. Porte do PWA "Pressão Arterial" com duração, braços, pulso e períodos configuráveis.

- Original (somente leitura, para comparar o visual): `reference/`
- ID do app: `br.com.danielsistemas.diario_pressao`
